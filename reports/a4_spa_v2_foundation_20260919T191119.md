## 1. What changed (all in `static/index.html` unless noted)

### 1.1 v2 redesign CSS — embedded, gated, token-driven
New styled block between `/* ==== A4 SPA V2 REDESIGN: BEGIN/END ==== */` markers (inserted immediately after the A3 token block, inside the main `<style>`). Every rule is scoped to `html[data-theme-v2]` so it is **inert by default**. Four layers:
1. **Layout rhythm** — `.app-shell` max-width 1720px / `#mainContent` 1560px centered; intel-strip gap, control-strip padding/gap, table/gallery/masonry/focus-grid gaps via `--ns-space-*`.
2. **Typography scale** — token size ladder (`--ns-type-xs…xl`) for labels/values/titles/callouts; tabular numerals (`font-variant-numeric: tabular-nums`) on `#scoutTable`, result counts; uppercase micro-labels with letter-spacing.
3. **Component surfaces** — cards/table/stream/masonry via `--ns-color-bg-raised` + `--ns-elevation-sm/md` + `--ns-radius-base`; primary/ghost buttons, active states (`.cs-btn.active`, `.qf-btn.active`, `.sc-nav-pill.active`, drawer/dock chips) via `--ns-color-accent*` + soft fills; semantic badges via `--ns-color-pos/warn/neg/neutral`; popovers/proof/confirm + omnibar suggest via `--ns-elevation-lg` + `--ns-radius-lg`.
4. **Accessibility + motion** — `:focus-visible` outline in `--ns-color-accent-hi`; `prefers-reduced-motion` disables v2 transitions.

No existing class, element, or `:root` rule was renamed/removed; the A3 token block stays byte-synced with `shared/design-tokens.css` (sync guard still passes).

### 1.2 Dev toggle (manual/visual, dev-only)
- **Markup:** a dev-only `V2` chip (`#devV2Btn`, `aria-label`/`aria-pressed`, `hidden`) added to `.topbar-right` before the theme toggle.
- **JS:** `themeV2Param()` (`?v2=1`), `devParam()` (`?dev=1`), `NS.applyThemeV2(on)` (sets/removes `data-theme-v2` on `<html>`, persists `t2.kirklandScout.themeV2.v1` = `1|0` localStorage, mirrors `aria-pressed`), `NS.isThemeV2()`, `initThemeV2()` (boot: reads `?v2=1` OR the localStorage flag; exposes the chip only under `?dev=1`), and a chip click binding in `init()`.
- **Gate verified by test:** default boot leaves `data-theme-v2` OFF and persists `0`; setting the flag activates the attribute; `applyThemeV2(false)` removes it. The old theme remains the default (no attribute) — the full UI contract suite runs on v1-default.
