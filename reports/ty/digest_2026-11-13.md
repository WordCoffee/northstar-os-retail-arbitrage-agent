## PPC: unproven against real performance

**This is a fixture-level result, not a performance result.** The PPC score covers the *machinery*:
upload → propose → approve → write → download, plus today's output checks — the written bulk file
parses through the app's own parser with the same required columns and header order, reconciles
against the source (only approved rows, only approved values, nothing invented), and keeps every bid
inside the brief's declared cap.

It says **nothing** about whether an ad makes money. No campaign has run, no spend has occurred, and
no ad-versus-outcome evidence exists. A seller reading "PPC 3/5" must read it as: the file is
well-formed, the delta is honest, the budget is held — and the performance question is open. Closing
it needs real campaign history (the owner's own export, or a beta seller's), and that is not in this
run.

The ad-copy score is also fixture-level, and it assumes **Sponsored Products** caps — an assumption
flagged for the owner (`needs_you` PPC-2), not a product rule.
