# Research: closing the gap to the competitors

Run 2026-11-05, continuing until the owner says stop. Every result below came
from a real query through `tools/web_research.py` (journaled to
`logs/web_research.jsonl`), and every licence was read from the upstream
`LICENSE`/model card, not from memory. Raw results:
`state/evidence/research_sweep_20261105.json`, `research_sweep2_20261105.json`,
`vision_model_probe.json`.

One honest note on method: the GitHub unauthenticated search API rate-limited
mid-sweep (10 requests/minute, measured). `web_research.py` reported it as a
**transport failure**, not as "no results" — which is the behaviour the probe
(A5) requires. The Hugging Face API kept answering, so the second half of the
sweep is HF-only.

## 3. The experiments, in the order that moves the scorecard most

Each is scoped, measurable, and inside the standing rules (no Amazon, no spend,
local models only, licence recorded before use).

**E1 — Identity by editing, not conditioning (highest value).**
Generate the scene with FLUX 3, then composite the *real* product with
Qwen-Image-Edit-2511 (Apache-2.0, installed) using the product photo as the edit
source. Score with `picture_scorecard` `product_fidelity` on the subject crop.
Target: ssim >= 0.55 and pHash distance <= 24 on the 12-case dev set, versus the
measured 0.010-0.323 today. If editing still drifts, fall back to E2.

**E2 — Deterministic composite (the guaranteed path).**
BiRefNet cutout of the real product (installed) + generated scene + measured
shadow/contact shading. Identity is preserved *by construction* because the
product pixels are the user's own. Slower to look photoreal, never wrong about
the product. This is the fallback if E1 drifts, and it also fixes the
`KERT& SLATE` text problem for free (no diffusion on the label area).

**E3 — Parametric packaging families.**
Port packbox's parametric approach (MIT) so "a 500 g stand-up pouch, a
tuck-top box, a shrink sleeve" are *parameters*, not three new templates.
Acceptance: a family generates valid SVG + PDF with correct bleed/safe zones for
five sizes, and `prepress` passes at TAC <= 300.

**E4 — Research that cites claims, not files.**
Port the hyperresearch pattern (MIT): plan → search → fetch → extract → attach
the source URL + quote to each claim, and refuse a claim with no source. This is
the Perplexity gap, and it also makes the discovery loop auditable.

**E5 — Expose what we already wrote.**
`subagents`, `todos`, `plan_mode`, `skills` exist in `agent_kernel/` and are not
callable. No licence, no download, no gate — just wiring and tests. This is the
Claude Code gap and it is the cheapest item on the list.

**E6 — A demand/keyword layer over our own fixtures.**
Jungle Scout parity without touching Amazon: estimate demand from our own costco/
marketplace fixtures plus published aggregate statistics, track keyword rank over
our own snapshots, and always stamp the sample size. Acceptance: every number
carries its source and its n, and an unmeasured number is reported as unmeasured.

## 4. What this research deliberately did not do

- No Amazon request of any kind (the refusals are in `logs/web_research.jsonl`).
- Nothing non-commercial promoted to the cloud lane: FLUX.1 Kontext and the FLUX
  IP-Adapters are recorded as local-bench-only in `replace_later.md`.
- No package installed from this sweep. `packbox` and `hyperresearch` are
  **patterns to port**, not dependencies; if that changes they go through
  `vet_package.py` first (OSV), then `provider-suite.json` via a `GRANT:` commit.
- No claim that a candidate works. E1 and E2 are experiments with a measured
  pass/fail, not features announced in advance.
