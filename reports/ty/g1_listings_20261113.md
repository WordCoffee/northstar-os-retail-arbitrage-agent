## The exact refusal

`step-5-preview-free`, 360 ms):

```

http_status=400
error=HTTP 400
body={"error":{"type":"server_error","message":"Upstream request failed: Model is unavailable."}}
```

`GET https://opencode.ai/zen/go/v1/models` answers **200** (the key is accepted), and its
catalog no longer contains `step-5-preview-free`. It lists `step-5-preview` at
**$1.00 / $2.70 per 1M tokens** (paid) and three **$0** models the repo has never verified:
`beam-free`, `longcat-2.5-free`, `iceman-contributor-free`.

The adapter's documented behaviour is to refuse rather than substitute an unverified model,
so the compose stops with a business failure. Nothing was retried after the adapter's own
bounded retries; a paid model was never selected.

## Finding, recorded not fixed

and does not render the provider's HTTP status or message (`prop.error` is returned by the API
but never displayed). The 400 and its body had to be recovered with a server-side adapter
probe. The API response already carries the detail; surfacing it in the panel is a small UI
fix, filed here rather than taken in a job scoped to G1 verification.
