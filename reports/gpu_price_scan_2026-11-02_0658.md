## Caveats that change the answer

1. **Variant bait**: AliExpress/Alibaba listings titled "P4 8GB P40 24GB P100 16GB" or "3060 3070 3080 3090"
   show the cheapest variant's price on the card. The real SKU price is higher — you must open the listing
   and select the variant.
2. **SXM2 ≠ PCIe.** An SXM2 V100 will not run in a desktop board without an SXM2 baseboard/adapter.
3. **eBay "lowest price first"** is lowest *listed* price; OBO listings display the ask, not what they'll take.
   Auctions show the current bid, not the close price.
4. Import from CN/HK: customs, duty, return shipping, and no real warranty. Condition labels like
   "Open Box" / "New (Other)" on 8-year-old Teslas are seller shorthand for "pulled and cleaned".
5. eBay rate-limited this session intermittently (returned `Error Page`); every figure above came from a
   successfully rendered results page, and mixed-source prices were re-confirmed on a second pull where noted.
