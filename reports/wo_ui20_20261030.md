## 1. The audit changed the job

The brief assumes 20 gaps. The tree had roughly 7 real gaps, 10 partials and **3 items that were
dead code pretending to be done**:

| Claimed | Reality |
|---|---|
| Command palette (`Cmd/Ctrl+K`) | Two `CommandPalette.jsx` files, **imported by nothing**; no `metaKey/ctrlKey` listener exists anywhere in `src/` |
| Toast centre | `TOAST_PROVIDER` is **never mounted**; `useToast()` has zero callers |
| Celestial/galactic backdrop | `CelestialBackdrop.jsx` was unmounted last session; `GalacticBackdrop.jsx` (10 variants) is the real one and is now mounted |

That is why this pass is 7 builds + 10 upgrades + 1 harness rather than 20 builds.

## 4. Ready primitives (tested, adoption is per-surface)

These are complete and importable but not yet used by every page — claiming otherwise would be
false:

- `VirtualList.jsx` (item 9) — windowed rows, `visibleRange()` tested on 8 edge cases.
- `Reorderable.jsx` (item 10) — drag + placeholder + **Alt+Arrow keyboard parity**.
- `MarkdownEditor.jsx` + `Markdown.jsx` (item 16) — same grid cell for both modes (no jank),
  raw HTML never passes through, `javascript:` links are demoted to text.
- `useOptimistic()` (item 18) — rollback restores a snapshot and re-applies later in-flight updates.
- `useWorkspaceState()` (item 20) — allowlist + version + 14-day TTL, writes on `pagehide`/hidden.
- `useHoverIntent()` (item 8) — 90 ms intent delay, once-only, failures swallowed.
- `Skeletons.jsx` (item 5) — card/rows/grid shapes that mirror final layout, `aria-busy`.
- `.tap` (item 7) — 90 ms press transform on the spring curve.

## 5. The guardrail earned its keep immediately

First run of `check-contrast.mjs` failed two real, shipped colours:

```
FAIL  3.09:1  low-emphasis label on paper   (--ink-soft  #8a8a7a)
FAIL  2.87:1  warning text                  (--status-warn #b8860b)
```

Solved for the minimum change that preserves hue: `#6e6e61` (4.55:1) and `#8e6708` (4.52:1).
Both are now asserted, so they cannot regress silently.

   or tested primitives, but most pages still hard-code their own padding and still render their own
   loading state. A full sweep of every surface is a second pass, not this one.
2. **No visual verification by me.** Chrome Connect does not allow localhost and Playwright is not a
   sanctioned path here, so "looks right" is the operator's check on `:8101`.
3. **Phase 7 (FLUX 3) not run.** ComfyUI and the gateway are down; a render evicts everything and the
   box currently has no GPU work in flight to protect. Nothing raster was generated.
4. **Pending work orders not advanced.** Coder-lane pass@3 is still n=1; the creative lane
   (`IQ3_S-mtp`) has never produced full un-truncated files; FLUX 3 gateway end-to-end (Step 4) is
   still open; `known_issues` needing an operator decision (Costco untracked files, RealESRGAN
   upscale, scout table contract, DataForSEO spec) remain untouched.
