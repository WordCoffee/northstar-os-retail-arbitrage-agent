1. **Reproduce**: Execute the build command and capture the full output to identify the first error message.
2. **Diagnose**: Analyze the error context to isolate the specific root cause (e.g., syntax error, missing dependency, or configuration mismatch).
3. **Remediate**: Apply the targeted fix to the source code or configuration file.
4. **Verify**: Re-run the build command and confirm the exit code is `0`.
5. **Document**: Record the identified root cause and the specific change made to resolve it.
