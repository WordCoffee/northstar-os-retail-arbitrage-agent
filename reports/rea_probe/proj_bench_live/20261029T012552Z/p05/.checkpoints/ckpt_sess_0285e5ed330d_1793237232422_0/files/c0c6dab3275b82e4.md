1. **Reproduce**: Run the build command in the project root and capture the full output to identify the first error message.
2. **Diagnose**: Analyze the error context (file, line, and message) to determine the specific root cause (e.g., syntax error, missing dependency, type mismatch).
3. **Fix**: Apply the minimal code change required to resolve the identified root cause.
4. **Verify**: Re-run the build command and confirm the exit code is `0` with no error output.
5. **Document**: Record the root cause and the fix applied to complete the task.
