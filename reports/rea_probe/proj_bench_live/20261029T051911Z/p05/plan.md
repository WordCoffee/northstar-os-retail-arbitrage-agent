1. **Reproduce**: Execute the build command in the root directory and capture the full output to identify the first error message.
2. **Diagnose**: Analyze the error context (file, line, and type) to determine the specific root cause (e.g., missing dependency, syntax error, or configuration mismatch).
3. **Remediate**: Apply the minimal code or configuration change required to resolve the identified root cause.
4. **Verify**: Re-run the build command and confirm the exit code is `0` with no error output.
5. **Document**: Record the root cause and the applied fix in the project log or commit message.
