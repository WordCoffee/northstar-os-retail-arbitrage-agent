1. **Identify Target Assets**: List all canvas assets requiring documentation and assign a unique identifier to each.
2. **Retrieve Source Data**: Access the original design files, asset manifests, or API endpoints to extract the exact width and height values for each asset.
3. **Verify Provenance**: Cross-reference the extracted dimensions with the source metadata (e.g., file properties, commit history, or documentation links) to ensure the data is authentic and traceable.
4. **Compile Documentation**: Create a structured table mapping each asset identifier to its verified canvas size and the specific source reference (URL, file path, or version hash).
5. **Audit for Compliance**: Review the final table to confirm every row contains a valid size and a corresponding source citation, rejecting any entries lacking provenance.
