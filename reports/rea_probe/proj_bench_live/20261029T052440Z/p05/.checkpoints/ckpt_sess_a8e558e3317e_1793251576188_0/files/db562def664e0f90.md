1. **Reproduce & Isolate**: Run the build command to capture the full log; identify the first error message and the specific file/line where it occurs.
2. **Diagnose Root Cause**: Analyze the error context (e.g., missing dependency, syntax error, type mismatch) to determine the fundamental cause.
3. **Apply Fix**: Modify the code or configuration to resolve the identified root cause.
4. **Verify Clean Build**: Re-run the build command and confirm the exit code is `0` with no error output.
5. **Document Resolution**: Record the root cause and the fix applied to ensure traceability.
