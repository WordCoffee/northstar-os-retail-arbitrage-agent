1. **Access**: Log in to the admin panel using read-only credentials or a dedicated inspection account.
2. **Locate**: Navigate to the specific section containing the target value.
3. **Capture**: Record the exact value by taking a screenshot or copying the text, ensuring the value is explicitly quoted in the report.
4. **Verify**: Confirm that no actions (clicks, edits, or submissions) were performed that would alter the system state.
5. **Report**: Submit the findings with the quoted value and the evidence (screenshot/log) attached.
