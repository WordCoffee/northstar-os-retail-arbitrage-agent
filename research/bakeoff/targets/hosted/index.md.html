OpenCode is an open source coding agent. Use it in the desktop app, in the terminal, on your phone or from your own code with the SDK. [Read the docs](https://opencode.ai/docs/). - **[Any model](https://opencode.ai/docs/models/):** 200+ LLM providers through Models.dev, including local models - **[Any device](https://opencode.ai/docs/):** A desktop app, a terminal interface, a mobile app and an SDK for your tools - **[Multi-session](https://opencode.ai/docs/cli/tui/#sessions):** Start multiple agents in parallel on the same project - **[Plugins](https://opencode.ai/docs/plugins/):** Write plugins to hook into events and extend OpenCode with your own logic - **[MCP servers](https://opencode.ai/docs/mcp-servers/):** Connect local and remote MCP servers to give agents new tools - **[Custom agents](https://opencode.ai/docs/agents/):** Create specialized agents with their own prompts, models and tools - **[Agent skills](https://opencode.ai/docs/skills/):** Teach agents reusable workflows with SKILL.md files - **[Custom commands](https://opencode.ai/docs/commands/):** Turn repetitive tasks into slash commands you can run anytime - **[Permissions](https://opencode.ai/docs/permissions/):** Choose which actions run automatically and which need your approval - **[Undo and redo](https://opencode.ai/docs/snapshots/):** Roll back recent changes to your files and conversation with /undo ## Get started The easiest way to start is to [download OpenCode](https://opencode.ai/product) and use the [free models](https://opencode.ai/docs/console/models/#free-models).
