# Listing copy

Read `product-marketing` first. Everything here assumes its facts and claims rules.

## Title

- Lead with the primary keyword phrase a buyer would actually type, then the differentiator,
  then the size/count. Brand first only if the brand carries recognition.
- Hard cap 200 characters; aim for 120–150 so mobile truncation keeps the differentiator visible.
- No ALL CAPS words, no promotional language, no emoji, no seller name, no price or shipping.
- One product per title. A bundle must say what is in it and how many.

## Bullets

- Five bullets, each starting with a short CAPS benefit label, then the concrete detail.
- Cap 500 characters each; 150–250 is the useful range.
- Order: the job the buyer is hiring the product for → the proof (spec, material, size) → the
  usage occasion → the compatibility or storage detail → the risk-reducer (what it replaces,
  what is included). Never waste a bullet restating the title.
- Each bullet must be falsifiable from the supplied facts. If it is not, cut it.

## Description

- Cap 2000 characters. Open with the problem in the buyer's words, then how the product solves
  it, then the specifics, then what is in the box.
- Plain prose or short paragraphs. No keyword stuffing; a repeated phrase reads as spam and
  adds nothing the title has not already earned.

## Backend search terms

- Under 250 bytes, space-separated, no commas, no repetition of words already in the title.
- Include synonyms, misspellings a real buyer types, and the use-case nouns. Never include
  competitor brand names or trademarked terms.

## Prohibited in any field

Best, best seller, #1, guaranteed, money back, free, 100%, amazing, miracle, cure, heal,
medical, FDA approved, as seen on TV, limited time, act now, don't miss, eco-friendly or
organic without a certificate on file.

## Review before return

For every line ask: *could the operator defend this to Amazon with a document?* If not, it does
not ship.
