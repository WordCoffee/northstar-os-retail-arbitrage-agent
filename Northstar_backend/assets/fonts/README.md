# Compositor fonts

- `PlayfairDisplay.ttf` — Playfair Display (variable, weight axis), SIL Open Font License 1.1
- `Inter.ttf` — Inter (variable, opsz+wght axes), SIL Open Font License 1.1

Downloaded from the official google/fonts repository (ofl/playfairdisplay, ofl/inter).
Both licenses permit bundling and commercial use of rendered output; the fonts
themselves remain under the OFL (no resale of the font files as fonts).

Used by `mockup_compositor.py` for the deterministic typography pass
(on-image text is composited with real fonts, never generated by a model).
